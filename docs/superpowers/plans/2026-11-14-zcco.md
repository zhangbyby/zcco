# zcco Implementation Plan

> Historical plan: superseded by `2026-11-14-macos-native.md` after the user narrowed support to macOS and revised whitespace/output behavior.

> **For agentic workers:** Use superpowers:executing-plans to implement this plan task-by-task. Track steps below.

**Goal:** Pipe UTF-8 command output into the macOS or Linux clipboard.

**Architecture:** A dependency-free Rust CLI reads stdin, removes leading/trailing CR/LF, invokes an installed clipboard utility, then prints the copied text and confirmation unless quiet. Use pbcopy on macOS; prefer wl-copy on Wayland and xclip/xsel on X11.

**Tech Stack:** Rust 2024, std only, native clipboard utilities, GitHub Actions.

**Spec:** User requirements in this conversation; user requested coding to begin. Implementation proceeds in the current unborn repository without creating commits or worktrees.

## Global Constraints

- Name: z-copy command output; executable: zcco.
- Support macOS and Linux, including cross compilation.
- Strip only boundary CR/LF; preserve spaces and internal newlines.
- Default stdout: copied text, newline, `zcco已复制到剪贴板`, newline.
- `-q` / `--quiet` suppress success output; errors remain on stderr.
- Only print success after clipboard command completes successfully.

## Review Focus

- Clipboard utility missing or failing: nonzero exit, actionable stderr, no success output.
- Empty input: copy empty text, consistently supporting clipboard clearing.
- Invalid UTF-8: reject before touching the clipboard.
- Large input: no deadlock while writing to the clipboard subprocess.
- No graphical Linux session: explain that a Wayland/X11 session is required.
